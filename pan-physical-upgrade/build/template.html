How to use the Physical Upgrade Planner

Each topic has In plain words for anyone and Technical detail for engineers. Everything runs in this browser and nothing is uploaded. The page is offline by default.

1. Start here: plan a firewall refresh in four steps
  1. Get the old firewall's tech-support file. Device > Support > Generate Tech Support File, then download it. For an HA pair use the active unit. A tech-support file is sensitive: do not post or e-mail it.
  2. Drop it on the page. (.tgz, .tar.gz or .zip; a running-config.xml also works but has no usage data for sizing.)
  3. Walk the tabs left to right. Current device, Pick the new firewall, Hardware & cabling, Licenses, Convert, Report and runbook. A value that is not in the file says not in file; the tool never guesses.
  4. Convert and export. On Convert, load a real (non-sanitized) config export, convert, and download the XML and change log. Export the report and cutover runbook.
2. Why a second file for the conversion

In plain words: the tech-support file hides passwords and keys, and PAN-OS will not load a config in that state. To get a config you can load, export running-config.xml as a superuser (Device > Setup > Operations > Export named configuration snapshot).

Technical detail: without it the tool still sizes and converts, but encrypted values stay as placeholders, so the converted file is for checking structure and references only.

3. The model catalog: offline by default

In plain words: the list of Palo Alto models and end-of-life dates is built into this page, so it works with no internet. The badge in the header shows where the list came from. If you want to look for a newer list, click Check for newer catalog.

Technical detail: a strict Content-Security-Policy blocks all network access. Clicking Check for newer catalog reloads the page in online mode (?online), where the policy allows raw.githubusercontent.com only, then fetches one JSON file. The newer list is used only if its data_as_of is the same or newer. You can also load a catalog JSON yourself with Catalog file; that never touches the network.

4. Sizing rules worth knowing
  • Sizing uses measured peak plus headroom (30% by default); type a number in any box to override it.
  • Panorama must run the same or a newer PAN-OS than the firewalls it manages. Upgrade Panorama first if the new model needs a newer release.
  • Tick Hide serial numbers before you share screens or the report.
5. Troubleshooting
  • "Check for newer catalog" says it failed: the page is offline or the network blocks raw.githubusercontent.com. The bundled catalog is still in use.
  • The reload cleared my file: switching to online mode reloads the page. Check for the catalog first, then load your file.
  • PAN-OS rejects the converted file: you converted from a sanitized tech-support config. Load a real export on the Convert tab.
