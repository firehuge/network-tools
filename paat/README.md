# PAAT: Policy Automation and Analysis Tool

PAAT turns a firewall change request into a **planned, approved, audited and verified** rule change for
**Palo Alto Networks PAN-OS firewalls and Panorama**. It traces a flow through every firewall and virtual system on its
path, tells you every place a rule is needed, writes the change plan, and (only after approval, and only when you turn it on)
pushes it through Panorama and checks the result. It has a web GUI, a command line (`paat`, also installed as `panlab`)
and a read-only API.

PAAT is the server companion of [FlowMapper](../flowmapper/README.md), the offline single-page tracer: both run the same
path-tracing engine (`vendor/flowmapper/`, synced from `../flowmapper/build`).

## What it does

- **FCR upload and change plans:** spreadsheet requests become placed, grouped, CR-ready plans (GUI steps, `set` CLI,
  rollback and verification).
- **Trace a flow:** per-hop verdicts across Panorama, firewalls and virtual systems, diagrams (SVG, PNG, draw.io).
- **Decommission, App-ID advisor, EDL self-service, URL-filter self-service, OS upgrade planning.**
- **Users, roles and per-customer scope**, two-person approval, audit log, off-box backup destinations.
- **Safe by default:** plans and dry runs only; live pushes and OS upgrades are explicit opt-ins.

## Blank by design

A new install has **no customers, devices, users (apart from the first admin you create), lists or site codes**. See
"Your data is not included" in [INSTALL.md](INSTALL.md).

## Layout

```
paat/
  src/panlab/        Python package (CLI + web app); the `paat` command
  vendor/flowmapper/ path-tracing engine (verbatim copy of ../flowmapper/build) + cli.js runner
  customers/         empty; profile.example.yaml is the template
  templates/         blank FCR request form (generated by tools/make_fcr_template.py) and change-plan template
  docs/user-manual/  the manual (also served in the GUI at /help)
  deploy/            optional systemd timer for the EDL sweep
  docker/, Dockerfile, docker-compose.yml, install.sh
  tests/             unit tests with synthetic fixtures only
```
