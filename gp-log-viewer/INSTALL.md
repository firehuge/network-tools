# Install

There is nothing to install on a server. The viewer is one file.

1. Download `gp-log-viewer.html` (from a release, or copy it from this repository).
2. Put it anywhere: your desktop, a shared folder or an internal web server.
3. Open it in a current browser. It works offline.

Not supported: `.7z` files and password-protected zips (re-save as normal `.zip`).

Your log files stay on your computer. Do not commit real log bundles to this repository; the repository `.gitignore` blocks them.
